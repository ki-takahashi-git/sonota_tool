# 内外エレ日程表 取込自動化 セットアップ手順

## 概要
得意先から届く「タカハタ電子日程表YYYYMMDD.xlsx」の内容を、Googleスプレッドシート
「内外エレクトロニクス生産計画」(生産計画シート)へ自動で転記します。

- 新規判定: 「注番」+「NEI注文番号」の組み合わせが未登録なら新規注文とみなす
- 数量分の行複製: 数量が5なら同じ内容の行を5行(1台=1行)追加
- 工数・管理No.など数式で自動計算されている列は、直前行の数式をコピーして自動計算に任せる

**まずは検証用のコピーで試してから、問題なければ本番シートに反映してください。**
本番シート([内外エレクトロニクス生産計画](https://docs.google.com/spreadsheets/d/1VQoAyx76euNgH7DsQWljKPyp1oQbmQqjr-FWUL2-wEU))
は梅津さんが日常的に編集されているファイルなので、いきなり本番で試すのは避けます。

---

## 手順1: 検証用コピーを作る

1. 本番の「内外エレクトロニクス生産計画」をブラウザで開く
2. ファイル > コピーを作成 → 自分のドライブに保存(例: 「内外エレクトロニクス生産計画_検証用」)

## 手順2: スクリプトを設置する

1. コピーしたスプレッドシートを開く
2. 「拡張機能」>「Apps Script」を開く
3. デフォルトで開かれる `コード.gs` の中身を全選択して削除
4. 同じフォルダにある [`ImportSchedule.gs`](ImportSchedule.gs) の中身を全部コピーして貼り付け
5. 保存(フロッピーアイコン、または Ctrl+S)
6. スプレッドシートのタブに戻り、ページを再読み込み(F5)
   → メニューバーに「日程表取込」が追加されます
   → 初回実行時に権限の承認を求められるので許可してください
      (「このスプレッドシートを読み書きする」権限が必要です)

## 手順3: Excelを取り込んでみる

1. 得意先から届いた `タカハタ電子日程表20260819.xlsx` を用意
2. 検証用スプレッドシートで「ファイル」>「インポート」>「アップロード」
3. Excelファイルを選択
4. インポートオプションで **「新しいシートを挿入する」** を選んで「データをインポート」
   → 「タカハタ電子様」という名前のシートが追加されます
5. メニュー「日程表取込」>「取り込み実行」をクリック
6. 「新規注文◯件、追加される行数◯行」という確認ダイアログが出るので、内容を確認して「はい」
7. 生産計画シートの一番下に新しい行が追加されているか確認する
   - 部材支給・製造納期の日付が正しいか
   - 数量分だけ行が複製されているか
   - 工数の列が空欄になっていないか(型式の表記違いがあると空欄になることがあります)

## 手順4: 問題なければ本番に反映

検証用コピーで結果に問題がなければ、本番の「内外エレクトロニクス生産計画」にも
同じ手順(手順2・3)でスクリプトを設置して使えます。
(本番ファイルは梅津さんが所有者なので、スクリプトの設置には編集権限が必要です)

---

## 今回の打ち合わせでの前提・要確認事項

- **型式の表記**: Excelの表記をそのまま転記します(変換ロジックは入れていません)。
  Excel側(`-BOS-`等)とスプレッドシートの工数単価表側(`-P-KIT`等)で表記が違うと、
  工数のVLOOKUPが `#N/A` になることがあります。これは今のところ自動変換せず、
  **取込後に目視で型式を直してもらう運用**にしています。
- **注文日列(A列)**: 「スプレッドシートに登録した日」という意味なので、
  Excel側の日付ではなく、**スクリプトを実行した日(今日の日付)**を入れます。
- **並び順**: 追加するデータ同士を製造納期の昇順に並べ替えてから、
  既存データの一番下にまとめて追加します(既存データの並び自体はいじりません)。
- **グループの罫線**: 同じNEI注文番号の行(数量分)のかたまりごとに、
  NEI注文番号・型式の列へ太い罫線で囲みを付けます。
- **A列の色**: 実行するたびに、生産計画シートのA列の色を一旦すべてクリアしてから、
  今回追加した行のA列だけ赤色(`#ff0000`)で塗ります。
  → 実際の赤の色味が違う場合は `ImportSchedule.gs` 内の
  `CONFIG.NEW_ROW_HIGHLIGHT_COLOR` を書き換えてください。

## うまく動かない場合によくある原因

- 「見出し列が見つかりません」というエラー → `ImportSchedule.gs` 内の
  `CONFIG.MAIN_HEADERS` / `CONFIG.SOURCE_HEADERS` の文字列が、実際のシートの
  見出しセルの文字列と完全一致しているか確認してください(全角/半角、スペースの有無など)
- インポート後のシート名が「タカハタ電子様」以外になった場合 →
  実行時にシート名を聞かれるので、その名前を入力してください
- 工数の列が `#N/A` になる → 型式の表記違いが原因です。上記「型式の表記」を参照。
  取込後に該当行の型式セルを工数単価表の表記に合わせて手直ししてください。
