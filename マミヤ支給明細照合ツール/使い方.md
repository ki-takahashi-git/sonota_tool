# 支給部材PDF ⇔ 移動明細Excel 照合ツール

「タカハタ電子御中 支給部材_YYMMDD.pdf」(スキャンPDFの移動伝票)と
「タカハタ電子御中 移動明細_YY.M~.xlsx」(移動明細Excel)の内容を、
目視で照合していた作業を補助するツールです。

## 起動方法

- `マミヤ支給明細照合ツール.exe` をダブルクリック

## 使い方

1. **支給部材PDF**の「参照...」で照合したいPDFを選ぶ
2. **移動明細Excel**の「参照...」で移動明細のExcelファイルを選ぶ
   - 選ぶと**対象シート**の一覧が表示される
   - PDFのファイル名に日付(例: `_260908`)が含まれていれば、対応する
     日付のシート(例: `26.9.8出荷`)を自動で仮選択するが、必ず選ばれて
     いるシート名を確認すること
3. **［照合実行］**を押す(PDFのページ数に応じて数十秒〜数分かかる)
4. 結果が一覧表示される。行の色の意味:

   | 色 | 状態 | 内容 |
   |---|---|---|
   | 緑 | 一致 | 品番・数量ともに一致 |
   | 赤 | 数量相違 | 品番は一致したが数量が異なる → 要確認 |
   | 黄 | 要確認(OCR) | OCRの読み取りに自信が持てない → 必ず目視確認 |
   | 灰 | PDF/Excelに見つかりません | 片方にしか品番が見当たらない |

   確認が必要なもの(赤・黄・灰)が上に、それ以外(緑の一致)は
   PDFの行№順に並ぶ。

5. **［結果をExcelに出力...］**で、色分けされた一覧とサマリーをExcel
   ファイルとして保存できる(保存後、開くか確認される)

## 注意事項

- 本ツールはOCR(文字認識)による自動照合であり、100%の精度を保証する
  ものではない。黄色(要確認)の行は必ず元のPDFを目視で確認すること
- 移動明細Excelのうち、「簡易品名」などコード(品番)を持たない
  補材/返却品セクションは照合対象外
- 参照ダイアログは前回選択したフォルダを記憶する(PDF・Excel・
  出力先それぞれ別に記憶)

画面右上の**［使い方］**ボタンでもこの内容を確認できます。
