# 支給部材PDF ⇔ 移動明細Excel 照合ツール

「タカハタ電子御中 支給部材_YYMMDD.pdf」(スキャンPDFの移動伝票)と
「タカハタ電子御中 移動明細_YY.M~.xlsx」(移動明細Excel、対象シート)を
目視で照合していた作業を補助するツールです。

PDF側は画像スキャンのため、Windows標準のOCR(日本語言語パック)で
文字を読み取り、Excel側の品番・支給数と自動で突き合わせます。
数量欄は誤読しやすいため、明細行ごとに数量セルだけを高解像度で
再読み取りする検算処理を行い、精度を高めています。

## セットアップ(初回のみ)

1. Python 3.10以降がインストールされていること(Windows標準のOCR機能を使うため **Windows** で実行してください)。
2. 必要なライブラリをインストールします。

   ```bash
   pip install -r requirements.txt
   ```

   ※ 社内ネットワークでpipのインターネット接続ができない場合は、情報システム部門にご相談ください。

## 使い方

1. ツールを起動します。

   ```bash
   python shikyu_check_tool.py
   ```

2. 「支給部材PDF」欄で照合したいPDFを選択します。
3. 「移動明細Excel」欄で移動明細のExcelファイルを選択します。
   - ファイルを選ぶと「対象シート」にシート一覧が表示されます。
   - PDFのファイル名に日付(例: `_260908`)が含まれていれば、対応する日付のシート
     (例: `26.9.8出荷`)を自動的に選択しますが、必ず選ばれているシート名を確認してください。
4. 「照合実行」をクリックします。PDFのページ数に応じて数十秒〜数分かかります。
5. 結果が一覧表示されます。行の色の意味:

   | 色 | 状態 | 内容 |
   |---|---|---|
   | 緑 | 一致 | 品番・数量ともに一致 |
   | 赤 | 数量相違 | 品番は一致したが数量が異なる → 要確認 |
   | 黄 | 要確認(OCR) | OCRの読み取りに自信が持てない(品番の文字ズレ、数量が不明瞭 など) → 必ず目視確認 |
   | 灰 | PDFに見つかりません / Excelに見つかりません | 片方にしか品番が見当たらない |

6. 「結果をExcelに出力...」で、色分けされた一覧とサマリーをExcelファイルとして保存できます。
   保存後に開くかどうか確認ダイアログが出ます。

## 注意事項

- **本ツールはOCR(文字認識)による自動照合であり、100%の精度を保証するものではありません。**
  黄色(要確認)の行は元のPDFを目視で確認してください。
- 移動明細Excelのうち、「簡易品名」などコード(品番)を持たない補材/返却品セクションは
  照合対象外です(PDFの支給部材リストには対応する行がないため)。
- PDFのレイアウトが大きく変わった場合(列の並び順が変わった等)、抽出がうまくいかない
  ことがあります。その場合はご相談ください。
