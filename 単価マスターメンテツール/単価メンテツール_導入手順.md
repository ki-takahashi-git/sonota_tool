# 単価マスター メンテナンスツール（Excel版）導入手順

参考：コード情報検索ツールVer1.02（ADO接続方式）に準拠しています。
「抽出」シートに **メーカー品目コード** か **アイテムコード** を貼り付け →『単価検索』実行 →
「単価結果」シートに現行の単価情報（TID・適用期間・適用数量・発注単価・MOQ・警告）を表示します。

## 初回だけの準備
1. `単価メンテツール.xlsx` を開き、**.xlsm（マクロ有効ブック）として保存し直す**
   （ファイル → 名前を付けて保存 → ファイルの種類を「Excel マクロ有効ブック(*.xlsm)」）。
2. ダウンロード由来でブロックされる場合：ファイルを右クリック → プロパティ →
   下部の「許可する / ブロックの解除」にチェック → OK。開いたら「コンテンツの有効化」。
3. `Alt + F11` でVBA画面を開く → 左の「VBAProject(単価メンテツール.xlsm)」を右クリック →
   **「ファイルのインポート」** → `単価メンテ_マクロ.bas` を選ぶ。
4. `Alt + F8` → 「単価検索」を選んで［実行］。よく使うならボタンに割り当ても可
   （開発タブ → 挿入 → ボタン → マクロ「単価検索」を指定）。

> 既存の「コード情報検索ツールVer1.02」をお使いの場合は、そのコピーに手順3で
> `単価メンテ_マクロ.bas` をインポートし、「単価結果」シートを1枚追加しても動きます
> （既にマクロ有効・ADO接続実績があるため確実です）。

## 毎回の使い方
1. 「抽出」シートの **A列（メーカー品目コード）** か **B列（アイテムコード）** の
   **片方だけ**に、3行目から貼り付ける（複数可）。
2. `Alt + F8` → 「単価検索」を実行。
3. 「単価結果」に表示。該当なしは「該当なし」。クリアは「クリア」マクロ。

## 表示・仕様
- メーカー品目コード＝前方一致（型式の (UL,RoHS等) や `<` 以降は自動除去して照合）。
- アイテムコード＝完全一致。`TD-` で始まるコードは除外。
- 1品目に複数の単価行（ロット別・期間別）があれば全て表示（適用数量→適用開始→適用終了 の順）。
- 警告：`単価未登録`（単価マスターに行が無い）／`無期限`（適用終了99/99/99）／`0円`。
- 接続はマクロ内に設定済み（さくらクラウド／TPICSDB_T／tdread：**読取り専用**）。

## 次段階（ご要望に応じて）
- 「一括登録」シートに改定単価・改定日を記入 → TPiCS読込用CSV（更新行＋新規行）を生成する
  マクロを追加できます。

## 一括登録CSVの生成（単価メンテ_CSV.bas）
`単価メンテ_CSV.bas` を、検索マクロと同じ要領で **もう1つインポート**してください
（Alt+F11 → 右クリック → ファイルのインポート）。マクロが2つ増えます：`結果を一括登録へ` と `CSV生成`。

### 使い方
1. `単価検索` で対象を表示。
2. `結果を一括登録へ` を実行 … TIDのある行が「一括登録」シートに転記されます。
3. 「一括登録」シートで各行に **改定単価** と **改定日**（例 2026/07/01）を記入。
   数量を変える場合のみ「新適用数量」、通常は区分「価格改定」のまま。新規追加だけにしたい行は区分を「新規追加のみ」に。
4. `CSV生成` を実行 … 保存先を選ぶとTPiCS読込用CSV（更新行＋新規行）が出力されます。
5. TPiCSの「テキストファイル読込み（単価マスター）」で取込み。**「同じキーがあれば上書きする」をオン**。

### 生成される行（価格改定の例：改定日 2026/07/01）
- ①更新行：現行TIDのまま、適用終了を `202606301`（改定日の前日）に＝現行単価を完了。
- ②新規行：TID空欄、適用開始 `202607011`、適用終了 無期限、発注単価＝改定単価。

出力列は `TID,CODE,VENDOR,TDATE,EDATE,TVOL,TEMA,PRICE,SPRICE,TAXRATE,TAXKUBU,HIMOKU`。
単価は丸めず現行値のまま出力します（数量・単価の末尾ゼロのみ整形）。
