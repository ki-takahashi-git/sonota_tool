# 単価マスター メンテナンスツール

TPiCS（さくらクラウドのSQL Server）の単価マスターを **読取り専用** で照会し、
価格改定の **更新行＋新規行** を TPiCS テキスト読込用CSV として生成するツールです。

- **(1) 閲覧ツール**：現行単価・TID・適用数量(TVOL)・アイテムマスターのMOQ(LOTS)・発注先名称・メーカー品目コードを一覧表示。
  MOQ不一致・無期限(99/99/99)残存・0円単価を自動で警告表示。検索はアイテムコード／メーカー品目コード／品名／発注先(名称・コード)。
- **(2) 一括登録CSV生成（Excel往復）**：①で選んだ品目の現行全ロット行をExcelに出力 → 改定単価・改定日を記入 → 取込むと
  更新行（現行TID／終了日＝改定日前日）＋新規行（改定単価／開始日＝改定日／無期限）を自動生成し、Shift-JISのCSVで出力。

> DBへは SELECT のみ。直接の書込みは行いません（修正履歴を残すため、登録はTPiCSのテキスト読込みで行う設計）。

---

## セットアップ（各PCで最初の1回だけ）
1. Python をインストール（https://www.python.org/downloads/、画面で「Add python.exe to PATH」にチェック）。
2. このフォルダ内の **「初回セットアップ.bat」** をダブルクリック（flask / pymssql / waitress / openpyxl を自動導入）。

※ exeは使いません（セキュリティソフトに引っかからないよう、Pythonスクリプトのまま動かします）。

## 毎日の起動
- **「単価ツール起動.bat」** をダブルクリック → 黒い画面は出ず、ブラウザが自動で開きます。
  開かない場合は `http://127.0.0.1:5000` を開いてください。
- 停止：**「単価ツール停止.bat」**（または再起動）。
- うまく動かない時の確認用に、コンソール表示の **「run.bat」** もあります（エラーが画面に出ます）。
- ショートカット化：「単価ツール起動.bat」を右クリック →「送る」→「デスクトップ（ショートテカットを作成）」。

## 使い方
### ① 現行登録 閲覧
- アイテムコード／メーカー品目コード／品名／発注先 で検索。警告（赤バッジ）を確認。
- 改定したい品目の行に ☑。複数の検索をまたいで溜められます（「選択 N件」表示）。

### ② 一括登録CSV生成（Excel往復・推奨）
1. 手順1「現行をExcelに出力」… ①で選んだ品目の現行全ロット行（TID付き）が出力されます（取りこぼし防止）。
2. Excelの「改定単価」「改定日」を記入（数量変更時のみ「新適用数量」、区分は通常「価格改定」）。
   仕入先の改定見積を見ながら記入／貼り付け。
3. 手順2「記入したExcelを取込む」… ファイルを選び「取込んでCSV化」→ プレビューを確認 →「CSVダウンロード」。
4. TPiCS の「テキストファイル読込み（単価マスター）」で取込み。**「同じキーのデータがあれば上書きする」をオン**。

少数のときは ②下部の「個別入力」で画面入力もできます。

## 設定（config.ini）
- `[app] demo` … `true` でデモ（DB未接続・サンプル）、`false` で本番。
- `[app] host` … 既定 `127.0.0.1`（このPCのみ）。`port` 既定 5000。`open_browser` … 起動時に自動でブラウザを開く。
- `[db]` … 接続先（既定でさくらクラウド／TPICSDB_T／tdread）。`auth = sql` か `windows`。
- `[columns]` … 列名の自動検出が外れた場合のみ上書き（例 `sect_NAME = BNAME`）。通常は不要。

## トラブル時
- 画面が出ない／`ERR_CONNECTION_REFUSED` … サーバーが起動していません。「単価ツール起動.bat」または「run.bat」で起動。
- エラーの記録は `app.log`（このフォルダ）に残ります。
- 列名の確認は、①画面の「DB項目を表示」（XSECTのサンプルも表示）。

## ファイル構成
- `app.py` … 本体（DB接続・API・Excel出力/取込）
- `core.py` … 日付変換・行生成・警告判定・数値整形（`python test_core.py` でテスト可）
- `templates/index.html` … 画面
- `config.ini` … 設定
- `初回セットアップ.bat` / `単価ツール起動.bat` / `単価ツール停止.bat` / `run.bat` / `run_demo.bat`
