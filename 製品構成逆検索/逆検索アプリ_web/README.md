# 製品構成 逆検索ツール（ブラウザ版）

Excel/VBA版「製品構成逆検索ツール Ver1.04」を、ブラウザで使えるWebアプリ（Flask）へ移植したものです。
検索ロジック（`core.py`）とマスタ取得層（`dbsource.py`）はデスクトップGUI版と共通です。

> DBへは SELECT のみ。書込みは一切行いません（`tdread` は読取り専用ユーザー）。

## できること
- **① 機種コード逆展開検索**：部品 → 使用する最上位**機種コード**・使用数(合計)・客先品目コード
- **② 直上親コード検索**：部品 → **直上親**(TD-で始まる仮親は自動スキップ)・名称・代表機種・メーカー名
- **CSV / Excel ダウンロード**

## 必要なもの
- Windows PC（さくらクラウドの SQL Server に到達できる回線 / VPN）
- Python 3.9 以上（https://www.python.org 。インストール時「Add python.exe to PATH」にチェック）

## 使い方
1. このフォルダ（`逆検索アプリ_web`）をPCに置く。
2. **本番（DB接続）**：`run.bat` をダブルクリック → ブラウザで http://127.0.0.1:5001 が開く。
3. **お試し（DB不要）**：`run_demo.bat` をダブルクリック → 内蔵サンプルで画面確認。

初回は必要なライブラリ（Flask, pymssql, openpyxl）が自動でインストールされます。

## exe化（Python不要で配布する場合）
1. `build_exe.bat` をダブルクリック。
2. `dist\GyakuKensaku_Web.exe` が生成されます。
3. exe をダブルクリックすると、サーバが起動し自動でブラウザ（http://127.0.0.1:5001）が開きます。
   停止するときは起動した黒いウィンドウを閉じてください。
4. `config.ini` を exe と同じフォルダに置けば、接続先を編集できます。
   - 注意：PyInstaller製のexeはセキュリティソフトのふるまい検知で誤検知（ブロック）される場合があります。
     その際は情報システム部門で許可リスト登録するか、exe化せず `run.bat`（Python実行）での配布をご検討ください。

## 画面の流れ
1. 起動するとマスタ読込が自動で始まり、上部に **進捗バー**（XITEM→XPRTS→XHEAD→XSECT→インデックス構築）が表示されます。
   100%になり右上が緑「本番(マスタ取得済)」になれば準備完了です（読込中は検索ボタンは押せません）。
2. 左の入力欄に部品コードを **1行に1コード** で入力。
3. 「① 機種コード逆展開検索」または「② 直上親コード検索」を押す。
4. 結果を確認し、必要なら「CSV保存」「Excel保存」でダウンロード。

画面右上の **「📖 操作マニュアル」** ボタンから、使い方・各列の意味・困ったときの対処を画面上でいつでも確認できます。

## 設定（config.ini）
- `[app] demo` … `true` でデモモード、`false` で本番。
- `[app] port` … 待受ポート（未指定なら 5001）。
- `[db]` … 接続先（既定：YOUR_DB_SERVER_IP / TPICSDB_T / YOUR_DB_USER）。

## ファイル構成
- `app.py` … Flask本体（API：status / search / download）
- `core.py` … 逆検索ロジック（DB非依存・`python test_core.py` でテスト可）
- `dbsource.py` … DB取得層 ＋ デモデータ
- `templates/index.html` … 画面
- `config.ini` … 設定
- `run.bat` / `run_demo.bat` … 起動
- `test_core.py` … 単体テスト

## デスクトップGUI版との違い
- 同じロジックをブラウザUIで操作します。社内の複数PCから1台のサーバに接続して共有する使い方も可能です
  （その場合は `app.py` の `host="127.0.0.1"` を `"0.0.0.0"` に変更してください。社内ネットワーク限定での利用を推奨）。
- マスタはサーバ起動後の初回検索時に読み込み、プロセスが動いている間は保持します。
  最新化したいときはサーバ（`run.bat` のウィンドウ）を再起動してください。
